# Business value measurement plan

## Incident assistant

Measure alert-to-triage time, time to first useful recommendation, percentage of incidents with a matching runbook, operator acceptance/rejection rate, false or unsafe recommendation rate, and audit completeness. Compare against a documented baseline using the same incident scenarios.

## Lead agent

Measure CSV import success, validation failure rate, enrichment completeness (only for approved source data), scoring agreement between reviewers, review time per lead, percentage marked qualified, and downstream conversion only when CRM outcomes are available. Report sample size and observation window. Do not claim conversion lift without a controlled comparison.
